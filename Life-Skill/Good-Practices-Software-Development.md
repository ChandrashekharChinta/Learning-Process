## Question 1: Which point(s) were new to you?

- **Sharing progress is important.**  
  I learned that posting regular updates on project is better than working quietly.

- **How you ask questions is important.**  
  Saying “it’s not working” is not clear. I need to explain properly what feature or exact code is not working.

- **Using group chat is better than private messages.**  
  It helps everyone see the discussion the get help from mates.

- **Focus is a skill.**  
  I did not know that deep focus is something we can practice and improve.


## Question 2: Which area do you need to improve? What will you do?

- **Ask better questions.**  
  I will explain the problem clearly, say what I tried, and share code bugs or screenshots of bugs.

- **Ask for help earlier.**  
  If I am stuck for 30–45 minutes, I will ask for help.

- **Improve my focus.**  
  I will work in short focused time blocks and avoid distractions while coding.
